# Imperials vs Rebels — V6

V6 adds:
- Tactical AI with target priorities, threat assessment, attack-before-move behavior, intelligent EMP use, and conditional specials.
- Optional Local Multiplayer mode for two humans on one computer.
- Existing V4/V5 battle rules retained: 2 AP per ship, permanent EMP, Tiny Kill-Ships without EMP, Large Ship Long-Range EMP, Plasma Jump, Command Burst recipient limit, custom fleets, and special moves.
